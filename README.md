# 🚀 PathForge AI

### Adaptive AI-Powered Career Learning & Roadmap Engine

> **Hackathon Project — IDEATHON 2.0**

---

## 📌 What It Does

PathForge AI is an adaptive career-learning platform that creates a personalized learning journey based on a learner's education, experience, skills, career goal, available time, and current learning level.

Instead of giving every learner the same roadmap, PathForge uses a **Machine Learning learner profiler**, a **rule-based decision engine**, and **Gemini AI** to determine where a learner should start, what they should skip, and what they should learn next.
